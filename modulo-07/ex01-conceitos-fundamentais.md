# Exercício 01 - Conceitos Fundamentais

## a. Qual é a função do AppServer?

O AppServer é o servidor do Protheus. Ele é responsável por processar as regras do sistema, executar os programas e fazer a comunicação com o banco de dados. É nele que acontece todo o processamento das informações.

---

## b. O que é o RPO?

O RPO é o repositório onde ficam armazenados os programas compilados do Protheus. Quando um programa é desenvolvido em ADVPL e compilado, ele é enviado para o RPO para que possa ser executado pelo sistema.

---

## c. Para que serve o Configurador (SIGACFG)?

O Configurador é a ferramenta utilizada para configurar o Protheus. Com ele é possível criar tabelas, adicionar campos, alterar propriedades de campos, configurar permissões e fazer outras personalizações sem precisar escrever código.

---

## d. Qual a diferença entre campo Real e campo Virtual no SX3?

Um campo Real é um campo que faz parte da estrutura da tabela e possui armazenamento no banco de dados. Já um campo Virtual é utilizado apenas pelo sistema para apresentar ou calcular informações durante a execução, sem fazer parte da estrutura física da tabela.
